🛠️ FixFinder

Home Service Platform – Project Documentation

A platform that helps customers find the right service and technician for their home problems.

1. Project Overview

FixFinder is a home service platform that helps users identify their home service problems and find suitable technicians.

Customer ↓ Login / Register ↓ Describe Problem ↓ Diagnose Problem ↓ Recommended Service ↓ Find Technician ↓ View Technician ↓ Book Service ↓ My Bookings

2. Customer Module

The customer module allows users to register, login, identify their home problems, view diagnosis results, find technicians and book services.

Customer Home Page – Screen 01

This is the main page of FixFinder. Customers can start the service finding process from this page.

Home Services – Screen 02

This screen displays the available home services that customers can explore.

Customer Login – Screen 03

Existing customers can enter their login credentials to access their FixFinder account.

Customer Registration – Screen 04

New customers can create an account by entering the required registration information.

Registration Success – Screen 05

This screen confirms that the customer registration process has been completed successfully.

Customer Dashboard – Screen 06

The customer dashboard provides access to important services, diagnosis, bookings and account activities.

Diagnose Problem – Screen 07

The customer describes the home problem. FixFinder uses the provided problem information to identify the appropriate service.

Diagnosis Result – Screen 08

The system displays the first stage of the diagnosis result based on the customer's problem.

Diagnosis Result – Screen 09

This screen provides additional diagnosis information, possible causes and related problem details.

Diagnosis Result – Screen 10

This screen continues the diagnosis result and presents the recommended service information.

View Technicians – Screen 11

Customers can view technicians who provide the required service.

View Technicians – Screen 12

This screen displays additional technician results available for the selected service.

View Technician Details – Screen 13

Customers can view technician information before selecting a technician for the service request.

Bookings – Screen 14

The customer can provide the required booking information and select the service.

Bookings – Screen 15

This screen continues the booking process where the customer confirms the required service details.

Booking Success – Screen 16

After successfully submitting the request, the system displays the booking confirmation.

My Bookings – Screen 17

Customers can view their submitted service bookings and booking information.

My Bookings – Screen 18

This screen provides additional booking information and allows customers to track their service requests.

3. Technician Module

The technician module allows technicians to register, login, view their dashboard, manage services and receive notifications.

Technician Registration – Screen 01

New technicians can register by providing their professional and account information.

Technician Registration – Screen 02

This screen continues the technician registration process and collects the required details.

Technician Login – Screen 03

Registered technicians can login to their account using their credentials.

Technician Dashboard – Screen 04

The technician dashboard provides an overview of service-related activities and requests.

Our Services – Screen 05

Technicians can view the services they provide through this section.

Our Services – Screen 06

This screen provides additional information about the services available to the technician.

Technician Notifications – Screen 07

Notifications provide information about new service requests and important updates.

4. Admin Module

The admin module allows administrators to monitor users, bookings and technicians in the FixFinder platform.

Admin Login – Screen 01

Administrators can login using their authorized credentials.

Admin Dashboard – Screen 02

The admin dashboard provides an overview of important platform activities.

View Bookings – Screen 03

Admin can view booking-related information submitted through the platform.

Bookings – Screen 04

This screen displays booking information available to the administrator.

Technicians – Screen 05

Admin can view the technicians registered in the FixFinder platform.

Technician Details – Screen 06

This screen allows the administrator to view detailed information about a technician.

5. Database

MongoDB is used to store FixFinder application data. The database contains information related to users, services, technicians and bookings.

Users Collection

The Users collection stores customer, technician and other user account information.

Services Collection

The Services collection stores the service information used by the FixFinder platform.

Technicians Collection

The Technicians collection stores technician information and service-related details.

Bookings Collection

The Bookings collection stores customer service booking information.

Overall Database

This screen provides an overall view of the FixFinder database structure and stored data.

6. Overall System Workflow

Customer ↓ Register / Login ↓ Customer Dashboard ↓ Describe Problem ↓ Diagnosis ↓ Recommended Service ↓ Find Technician ↓ Technician Details ↓ Book Service ↓ Booking Stored in MongoDB ↓ Technician Receives Request ↓ Admin Monitors Booking ↓ Service Completed
